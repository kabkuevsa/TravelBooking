TravelBooking

Система бронирования билетов и отелей на C# / ASP.NET Core Web API. Учебный монолит, готовый к декомпозиции на микросервисы.
✨ Возможности

    🔐 JWT-авторизация, роли User / Admin

    ✈️ Поиск рейсов и 🏨 отелей

    📝 Брони с расчётом стоимости и отменой

    💳 Мок-оплата, 📧 уведомления, 📊 админ-панель

    📚 Swagger UI

🛠 Стек

.NET 8 · ASP.NET Core Web API · EF Core · SQL Server (LocalDB) · JWT · BCrypt · Swagger
